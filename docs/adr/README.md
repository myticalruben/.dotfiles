# Architecture Decision Records

Toda decisión que cambie la arquitectura, el modelo de paquetes, la seguridad,
la marca o la experiencia de Mytical se registra aquí **antes** de implementarla.

Formato: contexto, decisión, consecuencias y estado. Un ADR aceptado no se
reescribe: se reemplaza por otro ADR que lo supersede.

| ADR | Decisión |
|---|---|
| 0001 | Overlay V1.0 antes de la ISO V1.1 |
| 0002 | APT/version propia es dueño del escritorio en la ISO |
| 0003 | Kitty es el terminal por defecto |
| 0004 | Nix estable 26.05, no `nixos-unstable` |
| 0005 | Jarvis híbrido: local primero, nube con consentimiento |
| 0006 | Una sola sesión Hyprland; wrapper de sistema |
